# 大模型评测方法论

> 从通用框架到 RAG 与 Agent 的工程化实践

本白皮书旨在为“大模型评测工程师”提供一套完整的全景作战图。摒弃单纯的工具堆砌，从底层失效模式出发，构建覆盖**安全合规、RAG质量闭环、Agent轨迹归因**的工程化评测体系。

## 📖 目录导航

- **[第一章 评测总论](chapter-1.md)**：明确评测的起点与决策需求，构建五层评测维度框架。
- **[第二章 RAG评测](chapter-2.md)**：拆解检索与生成层，探讨基于开发周期的评测闭环与工具选型。
- **[第三章 Agent评测](chapter-3.md)**：从“答案质量”走向“行为质量”，深入轨迹评测与因果归因。
- **[第四章 评测补充](chapter-4.md)**：探讨评测模型的选取、预算控制与工程化技术保障。
- **[第五章 常见问题](chapter-5.md)**：总结 LLM-as-Judge、RAG 与 Agent 评测中的典型坑点与解决方案。

!!! note "阅读建议"
    建议按照章节目录顺序阅读，在实际项目中遵循“先定失效模式 → 再选维度 → 再定阈值和工具 → 最后设计流水线”的原则。
